# Ícones das 12 categorias

Arquivos SVG prontos para uso no catálogo. Cada nome corresponde ao valor do campo `icon` da categoria.

| Arquivo | Nome no sistema | Categoria |
|---|---|---|
| `Building2.svg` | `Building2` | Gestão Condominial e Imobiliária |
| `Scale.svg` | `Scale` | Jurídico, Contábil e Seguros |
| `HardHat.svg` | `HardHat` | Obras, Engenharia e Laudos |
| `Wrench.svg` | `Wrench` | Manutenção Predial e Instalações |
| `Flame.svg` | `Flame` | Segurança e Prevenção de Incêndio |
| `Sparkles.svg` | `Sparkles` | Limpeza, Conservação e Controle de Pragas |
| `Leaf.svg` | `Leaf` | Resíduos, Meio Ambiente e Sustentabilidade |
| `Package.svg` | `Package` | Materiais, Equipamentos e Locações |
| `Wifi.svg` | `Wifi` | Tecnologia e Comunicação |
| `Users.svg` | `Users` | Serviços Operacionais e Mão de Obra |
| `HeartPulse.svg` | `HeartPulse` | Saúde, Bem-estar e Assistência Social |
| `Landmark.svg` | `Landmark` | Órgãos Públicos, Emergências e Utilidades |

URLs públicas (após deploy): `/icons/categories/Building2.svg`, etc.

No app React use `<CategoryIcon name="Building2" />` (componente Lucide) ou `preferSvg` para o arquivo estático.
